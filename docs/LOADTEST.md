# Нагрузочный прогон

Скрипт: `backend/tools/loadtest.py`. Коллектор запускается в отдельном от
тестовой биржи процессе (CPU биржи не учитывается) и подключается к
`mockexchange.py` по тем же протоколам, что к Binance Spot: WS
`depth@100ms` + `aggTrade`, REST-снимки, свечи, `aggTrades`.

```bash
cd backend
python tools/loadtest.py --symbols 1  --seconds 120
python tools/loadtest.py --symbols 10 --seconds 180
```

## Среда

* Облачный контейнер: 4 vCPU, 15 ГБ RAM, Linux 6.18 x86_64, Python 3.13.
* Синтетические книги: ~1300–2500 уровней на сторону, шаг сетки уровней
  0.0033 % цены; ~10 событий стакана и ~12 записей сделок в секунду на символ.
* Отсчёт стакана — 1 раз/с, запись в SQLite — каждые 2 с.

## Результаты (измерено 03.11.2026)

| Показатель | 1 инструмент, 120 с | 10 инструментов, 180 с |
|---|---|---|
| Сообщений WS в секунду (приём) | 22 | 220 |
| CPU процесса коллектора | 0.6 % одного ядра | 2.6 % одного ядра |
| Память (RSS в конце) | 49 МБ | 91 МБ |
| Задержка такта отсчёта, p50 / макс. | 1.8 / 6 мс | 1.2 / 63 мс |
| Запись в БД за такт, p50 / макс. | 0.3 / 0.9 мс | 1.1 / 5.8 мс |
| Разрывы последовательности стакана | 0 | 0 |
| Статус в конце | LIVE | 10 × LIVE |

Объём хранения на инструмент-минуту (после checkpoint WAL, `dbstat`):
карта глубины ~4.0 КБ, кадр стакана ~0.7 КБ, свеча ~0.5 КБ, футпринт ~0.3 КБ —
итого ~5.5 КБ/мин ≈ **8 МБ в сутки** на инструмент при ±3 % карты и шаге 10 USDT
для BTC. 14 дней хранения × 5 инструментов ≈ 0.55 ГБ.

## Стоимость отсчёта на больших книгах

Микробенчмарк `LocalBook.sample()` (все 6 полос + бакеты карты ±3 %):

| Уровней на сторону | Время отсчёта | 200 изменений уровней |
|---|---|---|
| 5 000 | 4.2 мс | 0.18 мс |
| 20 000 | 18.9 мс | 0.30 мс |

При 1 отсчёте в секунду книга BTCUSDT с 20 000 уровней на сторону занимает
~2 % ядра; 10 таких инструментов — ~20 % ядра.

## Ограничения прогона

* Это синтетическая нагрузка. Реальный поток Binance BTCUSDT в пиках даёт
  сотни сделок в секунду; против реальных бирж из среды разработки прогон
  не выполнялся (сетевой доступ к биржам закрыт).
* Отрисовка в браузере в прогон не входит: UI получает агрегаты 4 раза в
  секунду и рисует только видимые свечи.
